# Kinetic

**A personal workout tracking app for iOS, built with Swift and SwiftUI.**

Kinetic is an independently developed workout tracking application focused on making it easier to plan, record and review exercise sessions.

The project is an opportunity to explore iOS development, product design, data management and the process of building and iterating on a real application.

## Features

- **Workout tracking** – Record exercises and sets during active workouts.
- **Exercise library** – Manage an exercise collection, including editing and deleting exercises.
- **Workout history** – Review previously completed workouts.
- **Dashboard** – A central overview of workout activity and progress.
- **Weight preferences** – Switch between pounds (lbs) and kilograms (kg), while preserving previously recorded workout data.
- **Workout timing** – Track workout duration and display time consistently throughout the application.

## Technology

- Swift
- SwiftUI
- Xcode
- Git and GitHub for version control

## Development

Kinetic is being developed iteratively, with an emphasis on practical functionality, a clean interface and maintainable code.

Development includes:

- Building reusable components and shared extensions.
- Improving how workout and exercise data is stored and displayed.
- Refining the user experience across different parts of the application.
- Using Git branches to develop and organize individual features.

## Project Status

Active development.

Features and functionality are continuing to evolve as the application develops.
